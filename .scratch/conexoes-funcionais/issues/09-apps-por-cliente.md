# 09: Apps por cliente (Salesforce, Dynamics, Zoho, RD Station, Teams)

**What to build:** RD Station CRM e Zoho CRM (em avaliação). Salesforce, Dynamics e Teams ficam "Em breve" por decisão do dono (06/10/2026).

**Blocked by:** 01, 02 e 04.

**Status:** needs-info

## O que descobri
- **RD Station:** MCP oficial existe (CRM e Marketing), mas cada cliente gera a própria URL segura e o token no Catálogo MCP da RD; a página não diz se um app de terceiros pode se registrar para o cliente só fazer login. O dono pergunta à RD Station (pergunta pronta no guia). Plano B: o cliente cola a URL e o token na Althius.
- **Zoho:** o MCP do Zoho é por cliente (URL com chave). O caminho de "só login" é a API do Zoho com um app da Althius (multi-região), com ferramentas escritas por nós.
