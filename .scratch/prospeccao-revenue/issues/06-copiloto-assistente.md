# 06: Copiloto como assistente separado

**What to build:** O Copiloto deixa de criar execução que ninguém processa: conversa privada por pessoa, responde com números lidos do banco e encaminha trabalho ao agente certo. Não é quinto agente. Sem modelo disponível, diz a verdade.

**Status:** feito (ADR 0068, migration 135).

## Critérios
- [x] conversa persistida e privada por pessoa
- [x] números lidos do banco; nada inventado
- [x] encaminha trabalho ao agente certo (abre a conversa direta)
- [x] não é quinto agente; não cria execução nem gasta crédito (decisão na ADR 0068)
- [x] sem modelo, a tela diz a verdade
- [ ] conferido com um modelo real (sem chave neste ambiente)
